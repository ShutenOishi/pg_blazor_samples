# 第5段階の概要：一覧データ連携と編集

## この段階の位置づけ
MudTable/MudDataGridの取得方式を要件で選び、検索・ページング・編集・一括処理・性能を比較できる。

## 学習前に確認すること
第4段階のEF Core・PostgreSQL 18開発専用DB。

## WinForms・Dapperの経験とのつながり
DataGridViewへの一括読み込みと異なり、WebではDB取得量と描画量を分けて決める。Dapper/EFの違いだけで最適な一覧方式は決まらない。

## 初めに知る用語
Items、ServerData、Virtualize、DTO射影、キーセット、CancellationToken、xmin、EXPLAIN。

## 学ぶ順番（Step41〜60）
Step41〜45で標準的な一覧と検索、46〜50で射影・ページング・仮想化、51〜55で編集と競合、56〜60で期間・集計・性能・方式選定を学ぶ。各5ステップの後にコラム10〜13で復習する。

## 手を動かして確かめること
小規模一覧と大規模一覧の2条件から取得方式を選び、Count・ソート順・取消・同時編集の失敗時挙動を説明する。
