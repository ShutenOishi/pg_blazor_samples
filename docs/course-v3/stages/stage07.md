# 第7段階の概要：Webセキュリティ・AD認証とDB認可

> 教材v3の**完成後の構成案**。この段階の新規項目が未実装の場合、現行教材へ実装済みとして掲載しません。

## この段階でできるようになること
HTTP/Cookie/CSRFとWindows統合認証を理解し、既存DB利用者台帳を権限の正本として拒否を保証する。

## この段階の前提
第6段階のDB検索。AD/IIS実機確認は別。

## WinForms・Dapperとのつながり
Windowsログオン済みでも業務DBの全件が読めるわけではない。認証名と権限テーブルの照合を分ける。

## 練習課題と解答の確認点
未登録/無効/部署外の拒否、サービス経由以外の呼び出し、Count/CSVの漏えい否定を確認する。

**確認の基準：** 画面操作の結果だけでなく、処理がブラウザー・サーバー・DBのどこで動くか、例外や拒否をどう確認するかを説明できること。未実装の教材では学習結果の達成を宣言しません。
