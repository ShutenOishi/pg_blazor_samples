# 第2段階の概要：Blazorの基本と実行原理

> 教材v3の**完成後の構成案**。この段階の新規項目が未実装の場合、現行教材へ実装済みとして掲載しません。

## この段階でできるようになること
Razorの表示・イベント・コンポーネントと、SSR・SignalR・circuit・状態の違いを説明できる。

## この段階の前提
第1段階。DB/AD不要。

## WinForms・Dapperとのつながり
WinFormsのイベントがローカルで完結していたのに対し、Interactive ServerではC#がサーバーで実行される。
