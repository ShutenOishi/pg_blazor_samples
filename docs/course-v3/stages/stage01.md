# 第1段階の概要：Web開発の前提

> 教材v3の**完成後の構成案**。この段階の新規項目が未実装の場合、現行教材へ実装済みとして掲載しません。

## この段階でできるようになること
WinFormsとブラウザー/サーバーの役割を区別し、HTTPと開発者ツールで動作を追える。

## この段階の前提
C#とWindowsアプリ開発の経験。DB/AD不要。

## WinForms・Dapperとのつながり
フォームのイベントだけでは見えなかったHTTP要求・応答・DOM・HTTPSとKestrelを先に理解する。

## 学習の順番と到達点
- 学習順001：WinFormsとWebの処理場所を比較する（新規実装予定：web-01）
- 学習順002：URL・HTTPと要求／応答を理解する（新規実装予定：web-02）
- 学習順003：HTML・CSS・フォームの基礎（新規実装予定：web-03）
- 学習順004：開発者ツールでDOM・Network・Consoleを見る（新規実装予定：web-04）
- 学習順005：Visual Studio 2026でWebアプリを起動・デバッグする（新規実装予定：web-05）

## 5ステップごとに確認すること
- 学習順005の後：第1組の復習。直前の5テーマの関係を説明し、動作を再確認する。

## 練習課題と解答の確認点
Networkで要求と応答を観察し、HTMLの見た目を変えてサーバー側ブレークポイントを通す。

**確認の基準：** 画面操作の結果だけでなく、処理がブラウザー・サーバー・DBのどこで動くか、例外や拒否をどう確認するかを説明できること。未実装の教材では学習結果の達成を宣言しません。
