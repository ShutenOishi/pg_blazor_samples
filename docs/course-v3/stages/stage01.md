# 第1段階の概要：Web開発の前提

## この段階の目標
C#とWinFormsの経験を生かし、ブラウザーで表示される画面とWebサーバー上のイベント処理の違いを説明できるようになります。Razorへ進む前に、HTTP、HTML・CSS、開発者ツール、デバッグを確認します。

## 前提・実行環境
C#の変数・メソッド・イベントを学んでいること。Visual Studio 2026と.NET 10のBlazor Interactive Serverを使用します。この段階ではPostgreSQLやActive Directoryは不要です。

## WinFormsとの違い
WinFormsの多くの画面では、画面を表示する処理とC#のイベント処理が同じPC上で動きます。この教材のWeb画面では、ブラウザーがHTMLを表示し、C#のイベント処理はサーバー側で動きます。最初のHTTP取得と、その後の対話操作は通信の仕組みが異なります。

## 最初に知る言葉
**ブラウザー**はHTMLを表示するプログラム、**Webサーバー**はHTTP要求を受けて処理する側です。**HTTP**は要求と応答のための通信方式、**HTML**は要素の意味、**CSS**は外観を定義します。**DOM**はブラウザーの文書構造、**Kestrel**はASP.NET CoreのWebサーバーです。

## 確認課題と解答
**問1：** Web01のボタン操作でカウンターの値を変更するC#はどこで動きますか。

**解答：** この教材のInteractive Serverではサーバー上で実行され、変更後の画面表示がブラウザーへ届きます。

**問2：** Web02を再読み込みしたとき、Networkでは何を確認しますか。

**解答：** 主にDocumentのHTTP GETと応答ステータスです。対話型のイベント通知とは区別します。

**問3：** Web03でCSSの枠線を変更するとDBに保存したことになりますか。

**解答：** なりません。CSSは外観の設定であり、DB保存とは別です。
