# 第1段階の概要：Web開発の前提

> **第1段階の学習案内。** 5件の画面と復習コラムを追加しました。ビルドと実ブラウザー検証を経て受入を判定します。

## この段階でできるようになること
WinFormsとブラウザー/サーバーの役割を区別し、HTTPと開発者ツールで動作を追える。

## この段階の前提
C#とWindowsアプリ開発の経験。DB/AD不要。

## WinForms・Dapperとのつながり
フォームのイベントだけでは見えなかったHTTP要求・応答・DOM・HTTPSとKestrelを先に理解する。

## 学習の順番と到達点
- 学習順001：WinFormsとWebの処理場所を比較する（実装：web-01）
- 学習順002：URL・HTTPと要求／応答を理解する（実装：web-02）
- 学習順003：HTML・CSS・フォームの基礎（実装：web-03）
- 学習順004：開発者ツールでDOM・Network・Consoleを見る（実装：web-04）
- 学習順005：Visual Studio 2026でWebアプリを起動・デバッグする（実装：web-05）

## 5ステップごとに確認すること

[第1組の復習](../reviews/review-01.md)で、それぞれの実行場所と通信の違いを確認します。
- 学習順005の後：第1組の復習。直前の5テーマの関係を説明し、動作を再確認する。

## 練習課題と解答の確認点
Networkで要求と応答を観察し、HTMLの見た目を変えてサーバー側ブレークポイントを通す。

**確認の基準：** 画面操作の結果だけでなく、処理がブラウザー・サーバー・DBのどこで動くか、例外や拒否をどう確認するかを説明できること。未実装の教材では学習結果の達成を宣言しません。
