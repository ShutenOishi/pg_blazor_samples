# 学習順003：HTML・CSS・フォームの基礎

## このステップで学ぶこと
HTMLのlabelとinputの関係、CSSで見た目を指定する役割を学ぶ。

## 前提・環境
C#とWinFormsのイベントを知っていれば進められます。Visual Studio 2026、.NET 10のBlazor Web App（Interactive Server）を使用します。データベースとActive Directoryは不要です。

## 完成画面と操作
アプリで `/learn/web-03` を開きます。名前欄に「練習太郎」と入力し、プレビューが同じ値になることを確認する。

## 処理の流れ
HTMLで入力の意味と関連を定義し、CSSで枠・余白・フォーカスの見た目を指定する。

## 実装の場所
この教材では `src/PgBlazorSamples.Web/Components/Samples/WebFoundation/Web03Page.razor` に画面を実装しています。実際の画面を動かした後、RazorのHTMLと `@code` 内のC#を見比べてください。

## WinFormsとの対応
WinFormsは画面表示とイベントが通常同じPC上で動きます。この教材のWeb画面はブラウザーに表示され、Razorの対話イベント処理はサーバー側で動きます。HTTPでの初期読み込みと対話型のイベントを区別してください。

## 失敗時の確認
ブラウザーのConsole、Network、サーバーの出力ログを確認してください。ブラウザーから見えるURLやHTMLだけでは、サーバー側のC#の呼び出し結果をすべて判断できません。
