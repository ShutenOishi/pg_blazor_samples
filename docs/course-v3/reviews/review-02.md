# 第2組の復習：Razorと実行方式の復習

学習順006〜010の5テーマを、WinFormsからWebへの移行という視点で整理します。

## 確認事項
- 最初のBlazor画面とURLを対応させる
- RazorでC#の表示とHTMLを組み立てる
- Static SSRと対話型の実行場所を区別する
- 対話型のボタンがサーバーC#を呼び出すことを確かめる

## 演習
Static SSRのHTML内のボタンを押すと、必ずC#の@onclickが動きますか？

## 解答
いいえ。Static SSRのみでは対話型C#イベントは動きません。Interactive Serverなどの対話設定が必要です。

## 実習
これまでの5画面を開き、表示操作とサーバーC#の実行を確認します。状態を記録したままページを再読込し、失われる値と残る値を確認してください。
