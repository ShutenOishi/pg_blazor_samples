# 第9組の復習：ブラウザー機能と安全な操作

学習順041〜045を復習します。WinForms＋Dapper経験者がWeb固有の入出力・通信・アクセシビリティを区別するためのまとめです。

## 5つのテーマ
1. JS interopは必要なブラウザーAPIに限定する。フォーム計算などはC#とRazorで十分。
2. InputFileのaccept属性は選択補助。サーバーで拡張子とサイズを検査しOpenReadStreamへ上限を設定する。
3. CSVには日本語の架空データ、PDFには1ページの英字技術見本を出力する。業務データの出力では必ず再認可する。
4. ErrorBoundaryで例外の詳細を公開せず、取消・再試行の意味とDBトランザクションを分ける。
5. label、意味のあるHTML、Tab・Shift+Tab、200%拡大、:focus-visible、読み上げ可能な結果表示を確認する。

## 演習
学習用のテキストをアップロードして検査し、CSV/PDFを保存した後、わざと例外を起こして復旧し、画面拡大の状態でも入力・再試行できるか確認してください。

## 問題
**問1** acceptが.csvならサーバー側検査は省けますか。

**問2** ダウンロードボタンを隠せば、利用者に権限のない情報を出さずに済みますか。

**問3** エラー表示が正常に戻れば、DBトランザクションも自動で復旧しますか。

## 解答
1. 省けません。ファイル情報はサーバー側でも検査します。
2. 済みません。サーバー側の認可と行範囲制限が必要です。
3. 復旧しません。例外の表示とDB更新の原子性を分けて設計します。
