# 第17組の復習：Webの安全境界

**学習順081〜085** の復習です。各画面は架空の入力による模擬判定であり、ADや実DB台帳を認証・変更しません。

## 5ステップをつなぐ
1. HTTPの本人認証と暗号化Cookie、Blazorのcircuit、既存DB台帳による認可を区別する。
2. IIS/HTTPS経路とMiddlewareの順序を確認する。Antiforgeryと業務認可は異なる。
3. Razorの通常の文字列表示、HTTP要求のAntiforgery、SQLパラメーター化をそれぞれ確認する。
4. Secretの保存・鍵共有・Data Protection鍵の失効と障害復旧を理解する。
5. circuitが再接続しても現在の本人とDB権限を確認し直す。

## 問題と解答
**問1：** Windows認証済みならDBに未登録でも読み取れますか。

**答1：** 読み取れません。既存台帳に利用可能な本人・業務・部署の権限が必要です。

**問2：** MarkupStringを利用して外部入力をHTMLとして描画する必要がありますか。

**答2：** 通常の文字列表示では不要です。Razorのエンコードを使い、HTMLとして直接解釈させません。

**問3：** Cookie期限切れでもcircuitの画面が見えれば操作を許可できますか。

**答3：** できません。最新の認証と台帳権限をサーバー側で検証します。
