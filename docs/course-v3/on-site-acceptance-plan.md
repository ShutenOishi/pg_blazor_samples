| 時刻 | 開始/終了のUTC/JST、相関ID、Web/IIS/AD/DB/FDW/監査のイベントを対応付け |
| 合格 | 事前承認済み基準、期待/実測、判定 `PASS/FAIL/BLOCKED/NOT_RUN/N/A`、判定者、日時 |
| 原本 | 承認済みの**非公開**保管領域の参照ID、ファイルSHA256、収集手順、必要なマスキング記録 |
| 課題 | 事象、再現手順、影響、修復PR/CI、再試験対象（成功済みの無関係なCIは再実行しない） |

証跡用ファイル名の例：`SITE-04_YYYYMMDD-HHMMJST_manifest.json`、`SITE-11_YYYYMMDD-HHMMJST_load.csv`、`SITE-14_YYYYMMDD-HHMMJST_recovery.md`。これらは**命名例であり未収集**。GitHubには各ケースの状態、署名済みの判定概要、機密を含まないSHA256だけを記録する。秘密鍵、Kerberosチケット、Cookie、氏名/実アカウント、個人監査原本、接続文字列、内部ネットワーク情報、生DBダンプはコミット禁止。
