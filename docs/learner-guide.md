# はじめに：この教材の使い方

## 対象者
C#を学び始めた方、Windowsデスクトップアプリ開発からWebアプリ開発へ進みたい方、社内業務システムをBlazorで作りたい方を対象にしています。

## 学習環境
Visual Studio 2026と.NET 10（C# 14）を使用します。画面技術はBlazor Web App（Interactive Server）です。現在掲載しているステップ01〜25は、Active DirectoryやPostgreSQLがなくても学習できる構成です。ステップ21以降ではMudBlazor公式テンプレートの使い方と、日本語化のためのMudBlazor.Translationsも学びます。

## 進め方
1. 各ステップの「できるようになること」を読む。
2. Visual Studioでサンプルアプリを起動して指定の画面を開く。
3. 画面を操作し、期待される表示と比べる。
4. コード例を読み、どの処理が結果を変えたか説明する。
5. 演習に取り組み、チェック項目を確認する。
6. **5ステップごとの学習コラム**で重要な概念を結び付けて復習する。Step20の後は、ライブラリのDIを学ぶ特別コラム05も読む。

## 学習の全体像
| レベル | ステップ | 学習テーマ |
| --- | --- | --- |
| 1 | 01〜10 | Razor構文、イベント、画面の入力 |
| 2 | 11〜20 | DI、サービス設計、単体テスト |
| 3 | 21〜30 | MudBlazorの日本語業務画面 |

本版では**ステップ01〜25**と**学習コラム01〜06**を収録しています。ステップ26以降は順次拡充します。

## 用語
- **コンポーネント**：Blazorの画面を構成する再利用可能な部品
- **状態**：画面の表示を変化させるC#の変数やオブジェクト
- **DI（依存性注入）**：必要な部品を外側から受け取る設計
- **circuit（対話回線）**：Interactive Serverで画面とサーバーの対話状態を扱う単位

## セキュリティ上の注意
演習では架空のデータだけを使用してください。パスワード、実際の利用者情報、社内の機密データなどを入力する必要はありません。入力検証・認証・認可・DB保存は異なる機能として学びます。
