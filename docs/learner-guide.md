# はじめに：この教材の使い方

## 対象者と学習環境

この教材はC#、WinForms、Dapperの経験を生かしてBlazorのWeb開発を学ぶためのものです。Visual Studio 2026、.NET 10、Blazor Web App（Interactive Server）、MudBlazor、EF Core 10、PostgreSQL 18を使用します。サーバーで動くC#と、ブラウザーで動く画面を区別して進めてください。

学習項目は**学習順001〜110**です。アプリのトップ画面から対象を選ぶか、`/learn/001`〜`/learn/110`の正規URLを開きます。教材の題名と画面・実装コードは[全110件の実装ソース索引](course-v3/source-index.md)で直接確認できます。

## 進め方

1. 段階概要を読み、前提条件と操作の目的を把握します。
2. 対応する学習順の本文からRazor実装へ移動し、実際のイベントやサービスを確認します。
3. Visual Studioでアプリを起動し、教材に示す正規URLを開きます。
4. 操作結果とコードの処理位置を照合します。画面の表示、C#の実処理、SQLの実行は区別してください。
5. 正常例と拒否・取消・例外などの境界例を確認してから、演習と詳しい解答に進みます。
6. 5項目ごとの復習でWinForms＋Dapperとの共通点と相違点を整理します。

## 実行環境と安全上の注意

初期のWeb・DI演習にはADやDBを必要としないものがあります。PostgreSQL 18を利用する演習では**隔離した学習用データ**を使い、DB未設定の表示・SQL生成だけの画面と実DB処理を混同しないでください。利用者名・権限・業務データを入力して試す必要はありません。

Windows認証は本人の識別に使い、業務の操作・部署・行単位の認可は既存DB台帳を操作ごとに照合します。権限失効、監査不能、`xmin`競合、FDWの原子性を確認できない場合は安全に拒否します。画面の模擬判定やCIの成功は、実AD・IIS・Kerberos・FDWの現地実機受入を意味しません。現地受入は別に許可された試験と証跡が必要です。

## うまく動かないとき

画面が開かない場合はURLと起動プロセス、入力が更新されない場合は対話接続とC#イベント、DBの結果が得られない場合は設定と学習用PostgreSQLの実行条件を順に確認します。画面が表示されたことだけでDB書込み・認可・監査の成功を判断しないでください。
