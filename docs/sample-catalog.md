# サンプル一覧（80ステップ）

**ステップ01〜10はWindows/LinuxビルドとHTTP疎通を確認済みです。ステップ04〜10は実ブラウザー操作まで検証しました。** [前回の証跡（04〜06）](https://github.com/ShutenOishi/pg_blazor_samples/actions/runs/40260767597)／[追加の証跡（07〜10）](https://github.com/ShutenOishi/pg_blazor_samples/actions/runs/40264058164)。

**凡例**：「CIビルド・HTTP・ブラウザー操作済み」は画面操作をChromeで自動検証した状態です。「CIビルド・HTTP確認済み」は実ソースと日本語教材を追加し、Windows/LinuxのReleaseビルドとLinuxのHTTP画面疎通に合格したことを表します。実ブラウザーの操作・キーボード・接続復旧テストまで終了したことを意味しません。すべての受入条件を満たしたときのみ「検証済み」に変更します。

## 実装時の原則

- 新ステップは原則として小さな`.razor`コンポーネントと必要最小限のサービスで構成する。
- 各実装に[共通サンプル仕様](sample-specification.md)に従う日本語解説を設ける。
- どこからでも番号・題材・前提条件・サンプル画面へ到達できる目次を用意する。
- 01～30の教材で本物の業務データを扱わない。31～60は開発専用DBのみを使用する。61以降は認証・認可の検証を含める。
- SQLやAD環境が必要な例は実行条件を画面とドキュメントで明示する。
- 学習に必要な差分が大きい場合のみ独立プロジェクトや完成時点のタグを作成する。
- 誤って未実装の項目に「完成」「検証済み」を付けない。
