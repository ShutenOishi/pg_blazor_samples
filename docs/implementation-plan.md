## 作業単位と優先順位

1つのPRには原則**1つの学習テーマ群**を収め、画面・テスト・日本語解説をセットにします。大きな共通化は導入効果を確認してから行い、作業途中の古いサンプルを消さないことを優先します。

初めの実装PRは**ソリューション・目次・ステップ01～03・CI**を推奨します。次のPRで04～10へ進みます。今後ステップを増やすときも計画順序を目安とし、先行実装の必要性がある場合は依存関係を明記します。
