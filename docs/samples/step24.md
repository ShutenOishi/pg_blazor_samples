# ステップ24：MudFormで入力の妥当性を検証する

## できるようになること
MudFormの必須入力検証で業務固有のエラーを日本語で表示できます。

## 実際に操作する
1. /learn/24 を開き、未入力のまま「入力を検証する」を押します。
2. 「課題名を入力してください。」「学習内容を入力してください。」が表示されます。
3. 両方に架空の文字列を入力すると「入力検証に合格しました。」になります。

## ソースとの対応
```razor
<MudForm @ref="_form">
    <MudTextField T="string" Label="課題名（必須）" @bind-Value="_title"
                  Required="true" RequiredError="課題名を入力してください。" />
</MudForm>
```

`_form.ValidateAsync()`で検証し、`_form.IsValid`で合否を判定します。共通UIの翻訳はMudBlazor.Translationsに任せ、必須項目の説明など業務専用のメッセージだけ独自に記載します。

## 誤解
入力の必須チェックは、業務サービスのアクセス権やDB制約を保証しません。後続編で別に実装します。
