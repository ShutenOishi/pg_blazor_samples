# ステップ53：複数選択と原子的な一括更新

## できるようになること

選択IDとxminを渡して、50件以内の一括完了処理を全件成功・全件取消で実施する。 Visual Studio 2026、.NET 10、Blazor Interactive Server、MudBlazor 9、EF Core 10、開発用PostgreSQL 18を使用します。

## 前提条件

Step31〜50のDbContextFactory、CRUD、ServerData、楽観的排他を学んだ後に進みます。DB未設定の場合は実操作できず、日本語の設定案内を表示します。

## 画面で操作する

一覧で複数チェックを入れて「選択した件を完了にする」を押し、確認してから実行します。取消なら更新しません。操作後は成否にかかわらず選択を解除します。

## ソースのしくみ

LearningSelectionはIdとVersionを組で持ちます。サービスは重複・空選択・上限を検証し、単一DBトランザクション内で全行を読み直して版を照合します。1件でも違えば0件を確定します。

## 実務での注意点

EF CoreのSaveChangesとトランザクションを組み合わせ、見かけの一部成功を防止します。業務用の一括承認には保存時の行単位認可・監査の追加が必須です。 この教材にAD本人認証と業務認可はまだ実装していません。Step61〜70で学ぶまでは架空の開発用DBだけを操作してください。

## 確認問題と答え

**Q. 1件だけ他ユーザーが更新していたら？** 全件中止して0件確定したことを通知し、再読み込みで選択し直します。

## 自分で試す演習

成功操作と否定操作（空欄、DB未設定、競合、取消、行削除のうち該当するもの）をそれぞれ実行して、画面の日本語案内が異なることを確かめましょう。
