# ステップ18：DIと単体テスト

## できるようになること
本物の時計の代わりに固定時計を使い、画面を開かずにC#サービスをテストします。

## 画面を操作する
`/learn/18`で午前8時「おはようございます」、午後1時「こんにちは」を確認してください。どの時刻に操作しても結果は同じです。

## テストコードで確かめる
```csharp
[Fact]
public void 午前8時ならおはようございます()
{
    var service = new GreetingService(new FixedClock());
    Assert.Equal("おはようございます", service.GetMessage());
}
```

テスト用`TestClock`は`IClock`を実装し、時刻をテストケースごとに変えます。テストが受け取る対象はサービスだけで、ブラウザーやDBは不要です。

## Visual Studioでの実行
テストエクスプローラーから実行します。コマンドで実行する場合は`dotnet test`が使用できます。単体テストはWeb画面の操作テストと役割が異なります。

## よくある誤解
単体テストを作っただけでHTTPや認証処理まで確認できるわけではありません。今回は挨拶サービス・進捗サービス・課題サービスを対象にし、UIの操作は別のブラウザーテストで確認します。
