# ステップ68：集計とCSVにも認可を適用

## 到達目標

行集合の再使用、件数上限、式注入防止を実行例で理解します。Visual Studio 2026、.NET 10、MudBlazor、EF Core 10、PostgreSQL 18を用います。

## このステップで学ぶこと

CSVや集計もHTTP応答やダウンロードリンクから漏えいします。行単位権限と全量制限をサーバーの処理へ適用します。

## 画面の操作

1. 集計ボタンとCSVボタンをそれぞれ押す。
2. 匿名では集計値もダウンロードリンクも表示されないことを確認する。
3. 実DB試験で自部署の行のみがCSVへ入り、他部署のタイトルが含まれないことを確認する。

## C#とSQLのしくみ

CountByDoneAsyncとExportCsvAsyncは、どちらもVisibleで制限したIQueryableからDB側で取得します。CSVは101行取得して上限超過を判定し、1〜100件だけを出すときはEscapingを行います。

## 安全性と境界

業務用の利用者登録機能は作りません。認可の正本は管理者が構成する既存テーブル/外部テーブルを表す読み取り専用ビューです。匿名・権限なし・DB障害では拒否し、データやSQL結果を出しません。

実AD/IIS/Kerberosの認証成功はCIでは代替できません。業務で使う場合は実環境の接続方式・本人・権限更新・監査を別途受け入れてください。

## 確認問題と解答

**Q. 1万件のうち100件を返して「全件出力」としてよい？** いいえ。件数超過を明示して拒否します。
