# ステップ28：Snackbarと進捗の表示

## できるようになること
ISnackbarによる通知、処理中表示、二重押下防止、aria-liveによる状態読み上げを組み合わせます。

## 実際に操作する
1. 「/learn/28」で「練習用の処理を開始」を押します。
2. 一時的に進捗バーと「処理中」を表示し、操作ボタンが無効になることを確認。
3. 完了すると「練習用の処理が完了しました。」という本文とSnackbarが現れます。

## 重要なコード
```csharp
if (_running) return;
_running = true;
try
{
    await Task.Delay(400); // DB処理ではなく短い学習用の待ち時間
    Snackbar.Add("練習用の処理が完了しました。", Severity.Success);
}
finally
{
    _running = false;
}
```

## 誤解と実務上の注意
Snackbarは短時間で消えるため、重要な結果を本文の状態表示にも残します。長い処理を画面のTask.Delayで模倣しても本番のバックグラウンド処理を設計したことにはなりません。後続編ではジョブ実行、冪等性、取消と再接続を扱います。

## 演習
失敗メッセージを追加し、画面本文とSeverity.Errorを対応させます。
