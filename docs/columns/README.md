# 5ステップごとの学習コラム（全12回）

## ねらいと編集ルール
学習者が「コードは動いたが、なぜそうなるか説明できない」状態を残さないため、各5ステップの終わりに復習コラムを設けます。

**一つのコラムの構成：** 重要概念を結びつける説明／実務での使用場面／誤解と危険な使い方／確認問題と解答／次の5ステップへの橋渡し。教材には「実装済み」か「計画中」かを明記し、未実装の内容を実証済みと書きません。
