# サンプル作成テンプレート

教材v3では[全110件の学習順](course-v3/learning-sequence.md)と[配置を管理するJSON](course-v3/curriculum.json)を正本として、**学習順001から順に学べること**を最優先にします。既存Step01〜80は従来の`docs/samples/stepNN.md`とURLを維持します。新規教材は`docs/course-v3/lessons/<id>.md`と`/learn/<id>`を使用し、学習順を識別子とは分けます。

## ひな形

```markdown
# Step NN：題名

## できるようになること
このステップで習得する内容を1～3文で記載する。

## 前提
- 直前に理解しておきたいステップ：
- 必要なプロジェクト（Web/Application/Domain/Infrastructure等）：
- 導入する新しいDI登録・寿命（該当時）：
- 開発環境：
- PostgreSQLが必要か：
- AD接続が必要か：

## 完成イメージ
操作と画面の期待結果を具体的に記述する。

## 動かし方
1. ソリューションを開く。
2. 実行対象の画面を開く。
3. 入力や操作を行い、結果を確かめる。

## 仕組みの解説
新しく登場するC#・Razor・MudBlazor等を説明する。

## 重要なコード
必要な部分だけを抜き出し、日本語で説明する。

## よくある間違い
エラーの原因と切り分け方法を記載する。

## 演習
少しだけ変更して理解を確認する課題を設ける。

## 完了条件
- [ ] サンプルがビルドできる。
- [ ] 主な操作を確認した。
- [ ] 失敗ケースや入力エラーを確認した。
- [ ] 解説・コメントが日本語である。
```

## EF Coreと一覧を扱う教材の追加必須事項

Step31以降のDB学習とStep41〜60の一覧データ連携では、次の内容を毎回説明します。

- なぜ`Items`/`ServerData`/`VirtualizeServerData`/`MudTable`/キーセットのいずれを選んだか（使わなかった方式の理由も含む）。
- EF Core/Npgsqlの境界、DbContextFactory、接続・プールの寿命、CancellationToken、DTO、生成SQL。
- 全件取得の上限、ページングの安定ソート、Countの権限制限、検索条件の許可リスト、索引と実測。
- 編集系では楽観排他、二重保存、取消、トランザクション、画面破棄時の振る舞い。
- 正常系と、DB停止・競合・キャンセル・重複・ページ境界・権限漏れの否定テスト。
- 画面と日本語解説、サーバー側SQLとPostgreSQL結合テストを**同一PR**で用意し、未実装の設計例はその旨を記す。

設計と判断基準：[EF Core 10ガイド](efcore10-data-access.md)、[一覧パターン選択ガイド](data-grid-patterns.md)。

## サンプルの状態

- **計画中**：仕様のみ。
- **実装中**：コード・テストを作成中。
- **検証済み**：必須ビルドと動作確認、サンプル固有のテストに合格。
- **要修正**：回帰や環境差による失敗が確認された。

状態更新と教材へのリンクは[サンプル一覧](sample-catalog.md)へ反映します。PRで検証できない場合は「検証済み」にしません。

## DIを扱う教材に追加する説明

インターフェイス、登録場所、解決方法、Scoped/Transient/Singletonの寿命、Blazor Interactive Serverのcircuit特性、プロジェクト参照方向、テストでの差し替えを必ず解説する。初学者用サンプルからいきなりInfrastructureを要求しない。

## サーバー配備を扱う教材に追加する説明

Windows Server 2025のドメイン参加、IIS、Hosting Bundle、Windows認証、SPN、HTTPS、SignalR、gMSA（必要時）、PostgreSQLの最小権限、異常時の拒否を扱う。実環境未確認なら「検証済み」にしない。

## 5ステップごとの復習コラム（必須）

新課程では**学習順001〜005、006〜010、…、106〜110の5件単位**で復習を用意します。旧Step番号が5の倍数かどうかで新課程の復習位置を決めません。新規5件を実装する変更には、対応する復習と段階概要も同時に含めます。

- 新規・混合単位は`docs/course-v3/reviews/review-NN.md`、純粋な既存5件の単位は対応する`docs/columns/columnNN-NN.md`を再改稿する。概念の関連、誤解、実務応用、確認問題と解答を含める。
- 5件単位に対応する日本語の復習Razor画面：既存の画面を改稿するか、衝突しない新URLの復習画面を作る。
- `docs/columns/README.md`の状態更新、およびホーム画面・メニューの導線
- `scripts/build_docs_pdf.py`のPDF収録リストとブラウザーテスト

`python scripts/check-learning-materials.py`で、実装済みの各ステップ・5ステップごとのコラム・PDF収録対象に欠落がないことを検査します。ソースと文章の意味が一致するかは、従来どおりレビューと動作試験で確認します。

## PDF本文の読者

PDFは開発記録ではなく、学習者向けのテキストとして構成する。目次を「ステップNN：テーマ」の日本語で表記し、アプリ操作・実コード・演習に集中する。GitHub・PR・リポジトリの説明は学習者向け本文に収録せず、別の開発資料で管理する。

## EF Core 10教材の簡素化

Step31〜40はWeb/Data、Web/Servicesのみで完結します。Domain/Infrastructure/Repositoryの分割は必須ではありません。新学習順060（旧Step40の後）と061（旧Step41の前）の間に用途別MudBlazor特別コラムを置きます。
